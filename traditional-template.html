How to use in Photoshop: Right-click the SVG below → Save Image As (or use the Download button) to get the SVG file. In Photoshop, go to File → Open, select the .svg file, and set the rasterize size to your desired output (e.g. 3600×4800px for 18×24" at 200dpi). All elements are vector so they scale to any size with no quality loss.

To save as SVG: Right-click anywhere on the white composite below → View Page Source → copy everything inside the <svg>...</svg> tags and save as traditional-template.svg
